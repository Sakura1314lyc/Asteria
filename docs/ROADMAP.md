# 路线图

## 已完成

- 多来源学术检索、去重和排序
- 8 阶段可恢复工作流
- SQLite 项目库与报告版本
- 系统综述人工纳排门
- PDF/TXT/MD 全文与 FTS5
- 证据卡、质量提示、研究矩阵和文献图谱
- 后台作业与 REST API
- 插件发现、项目导出和回归评测
- arXiv/ACM 计算机方向映射和 DBLP 检索
- 算法、系统、基准、复现和研究议程专属产物
- React/TypeScript 本地 Web 工作台与 Python wheel 集成分发
- 报告、证据、图谱、产物、全文和项目导出 API
- 逐段引用—来源词汇对齐诊断
- Responses / Chat Completions 会话连接与五种 CS Agent 配置
- 项目级证据对话、持久消息与来源侧栏
- 显式研究问题保护与规划精炼策略审计
- 引用可评估覆盖、有效词汇对齐和保守评测
- 已完成筛选决定的人工复核与修改
- CLI 人类可读摘要与显式 `--json` 机器输出
- RIS、BibTeX/BibLaTeX 与 CSL JSON 文献库批量导入
- 导入事务、保守去重、元数据无损补全与稳定证据 ID

## 下一阶段
