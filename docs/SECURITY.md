# 安全与隐私

## API 密钥

- 可从环境变量、`.env` 或本地 Web 连接表单加载。
- `.env` 已加入 `.gitignore`。
- 项目导出不会包含环境变量或数据库文件。
- Web 提交的密钥只存于 `ConnectionRegistry` 进程内存；列表接口始终脱敏。
- 会话连接在服务重启后失效，数据库只记录连接 ID、名称和模型。
- “测试连接”会产生一次真实模型请求，只有用户显式点击时执行。
- Base URL 只接受不含凭据的完整 HTTP(S) 地址。因为它仍可指向内网地址，
  共享部署必须增加出站网络策略以防 SSRF。

## Prompt injection

论文标题、摘要和全文均视为不可信数据。模型提示明确要求忽略文献内部指令。尽管如此，仍应对高风险领域的输出进行人工复核。

## 文档

- 只接受 PDF、TXT、MD。
- 上传采用分块写入，默认上限为 50 MB，可通过 `PAPER_AGENT_MAX_UPLOAD_MB` 调整。
- 文件按随机文档 ID 存储，不使用上传文件名作为目录。
- 相同项目内按 SHA-256 去重。
- PDF 文本抽取不执行嵌入脚本。
- 扫描 PDF 需要独立 OCR 流程，当前不会静默伪造文本。
- Web API 响应不会返回内部 `source_path` 或 `text_path`。
- 运行产物下载只允许预定义扩展名和运行目录中的直接子文件。

## 文献库导入

- 只接受 `.ris`、`.bib` 与 `.json` 文件；JSON 按 CSL JSON 解释。
- 上传使用 `PAPER_AGENT_MAX_UPLOAD_MB` 限额，解析记录总数最多 10,000 条。
- 文件名会先取 basename，不作为数据库路径或服务器写入路径。
- 解析成功后才开启单个数据库事务；失败不会留下半批项目关联。
- React 默认转义导入的标题、作者和摘要；这些字段仍应被视为不可信内容。
- 去重只采用 DOI、arXiv ID 或精确规范化标题，不执行静默模糊合并。

## 网络服务

本地 API 无身份认证。若用于团队：

1. 放在带 TLS 的反向代理后；
2. 增加 SSO 或强认证；
3. 为项目实施授权；
4. 限制上传大小、请求速率和模型预算；
5. 将后台任务迁移到隔离 worker；
6. 对日志和导出应用数据保留策略。

开发环境 CORS 默认只允许 `127.0.0.1:5173` 和 `localhost:5173`。修改 `PAPER_AGENT_CORS_ORIGINS` 不等于增加认证。

## 学术数据

不要把受限、未发表、含个人健康信息或受保密协议约束的全文发送给外部模型，除非已获得明确授权并满足机构政策。
